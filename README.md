# SNIST Interactive University Map

## Project Overview
The **SNIST Interactive University Map** is a web-based campus navigation system designed to help students, parents, visitors, and newly admitted students easily locate buildings and facilities within Sreenidhi Institute of Science and Technology (SNIST).

The project provides an interactive campus map with location information and navigation support, making it easier to explore the campus.

## Objectives
- Help new students and parents navigate the campus easily.
- Provide information about campus buildings and facilities.
- Help users locate classrooms, labs, and other important places.
- Make campus navigation simple and user-friendly.

## Features
- Interactive campus map.
- Campus building and location information.
- Room and classroom search.
- Route navigation between the main gate and selected locations.
- Voice assistance.
- Dark mode support.
- User-friendly interface.

## Technologies Used
- HTML – Webpage structure.
- CSS – Styling and user interface design.
- JavaScript – Interactive functionality and navigation.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Right-click and select **Open with Live Server**.
5. The Interactive University Map will open in your web browser.
